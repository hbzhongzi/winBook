## 1. 开发目标与范围

- **目标**：按原文档 2.1，交付双击可启动的 Windows x64 程序，支持打开并正确显示 EPUB / PDF / TXT，错误可读，`wails build` 产物可在净机运行。
- **范围纪律**：本文档所有阶段的出口最终服务于原文档第 10 章验收标准；阶段门禁不过不进入下一阶段。
- **非目标**：与原文档 2.2 一致（编辑、批注、书架、进度持久化、云同步、MOBI/AZW3、DRM 初版不做）。

## 2. UI 基线（来自前端界面示例）

### 2.1 界面组成与组件映射

HTML 示例中的每个元素都有明确落地位置；实现后按本表走查一致性。

| HTML 示例元素 | 对应实现 | 数据来源 | 备注 |
|---|---|---|---|
| 标题栏文字（BookEditor — 书名） | Wails 窗口标题 + `runtime.WindowSetTitle` | book.name | 原生标题栏，非 React 组件 |
| 窗口控制按钮 / MOCKUP 标签 | — | — | 演示元素，不实现 |
| 「打开图书」按钮 | Toolbar.tsx | — | 触发 OpenBook()，进行中进入 loading |
| 书名 + 格式徽章 + 大小 | Toolbar.tsx | book.name / book.format / book.size | 徽章配色按 EPUB/PDF/TXT 区分 |
| 错误条（code chip + message + 关闭） | ErrorBar.tsx | AppError | 叠加态，可关闭，见 2.2 |
| TXT 正文（pre 保留换行） | TextViewer.tsx | book.text | 样式口径同落地文档 7.1 |
| PDF 画布 + 上一页/下一页/页码 + 缩放徽章 | PdfViewer.tsx | book.dataBase64 | 缩放徽章固定 120% |
| EPUB 目录侧边栏 + 正文 | EpubViewer.tsx | book.dataBase64 | 一级目录 + scrolled-doc |
| 状态栏（路径 + 状态信息） | StatusBar.tsx | book.path + 当前状态 | 编码/缩放/渲染模式+当前章节 |
| 欢迎空态（尚未打开图书） | BookViewer.tsx 空态分支 | — | 含"取消选择不提示"提示文案 |

### 2.2 应用状态机

状态集合：`empty`（空态）/ `loading`（打开中）/ `book-txt` / `book-pdf` / `book-epub`；**error 是叠加标志，不是替换状态**（失败时保留当前已打开图书）。

| 起点 | 事件 | 终点 | 表现 |
|---|---|---|---|
| empty | 点击「打开图书」 | loading | 按钮进入进行态 |
| loading | 成功（txt/pdf/epub） | book-对应格式 | 渲染对应 Viewer；标题栏/工具栏/状态栏联动 |
| loading | 用户取消 | empty | **静默**：无错误条、无提示、不清空当前内容 |
| loading | 失败 | empty + error | 首次失败即空态上叠错误条 |
| book-\* | 打开新书成功 | book-\*（新） | 旧 Viewer 先销毁（key 强制重挂载） |
| book-\* | 打开新书失败 | book-\*（旧）+ error | 旧书保留，错误条叠加显示 |
| error 条 | 点击关闭 | error 清除 | 不影响当前 book 状态 |

| # | 行为 | 关联任务 |
|---|---|---|

| B3 | 窗口标题联动（BookEditor — 文件名） | T205 |
| B4 | 状态栏路径与状态信息联动（编码/缩放/渲染模式+当前章节） | T304/T502/T602 |
| B5 | PDF 翻页：上一页/下一页 + 页码 x / N + 边界禁用 | T502 |
| B6 | PDF 缩放徽章固定 120% | T502 |
| B7 | EPUB 目录点击跳转，当前章节同步状态栏 | T602 |
| B8 | 错误条可关闭；取消打开不出现错误条 | T303/T701 |

### 2.4 UI 基线与实现的差异登记

| 示例中的处理 | 真实语义 | 处理方式 |
|---|---|---|
| 错误态与欢迎空态同屏展示（示例需演示四种状态） | 错误条为叠加态，不替换当前书籍态 | 按 2.2 实现；不算偏差，记录备查 |
| MOCKUP 标签、窗口控制按钮 | 演示元素 | 不实现 |
| loading 态未在示例中展示 | 打开图书期间的中间态 | 按 2.2 状态机实现（按钮禁用/加载提示），与示例不冲突 |
| 示例书籍文本为演示文案 | 与实现无关 | 不影响实现 |

### 4.2 阶段任务卡

**P1 骨架与主链路**
- 目标：工程可运行；打开 TXT 全链路（对话框 → Go → 前端分派 → 显示）与错误/取消路径打通；空态 UI 与 HTML 基线一致。
- 任务：T101–T402。
- 入口：环境核对通过（落地文档 2.1 全命令）。
- 出口 G1：① wails dev 启动正常；② 按 2.1 映射表走查，空态与 HTML 示例一致；③ UTF-8/GBK/BOM TXT 正常；④ 取消静默；⑤ .mobi 拒绝并提示"暂不支持"；⑥ 错误条可关闭；⑦ 标题栏/状态栏联动（B3/B4）。
- 阻塞处理：绑定未生成先查 wails.json 与绑定再生成；对话框不弹查 startup ctx 赋值。

**P2 PDF 渲染**
- 目标：PDF 逐页显示 + 翻页 + 边界行为；worker 加载在 dev 与打包两种形态均可靠。
- 任务：T206、T501–T505。
- 入口：G1 通过。
- 出口 G2：落地文档 M2 五项 Gate（单页渲染/多页翻页不越界/控制台无 worker 告警/30MB 可开并记录内存/损坏文件解析失败不崩溃）。
- 阻塞处理：worker 失败触发 T504（方案 B）；中文缺字按 F1 条件启用 cmap（落地文档 7.2）。

**P3 EPUB 渲染**
- 目标：EPUB 正文滚动显示 + 一级目录跳转 + 生命周期正确。
- 任务：T601–T604。
- 入口：G2 通过。
- 出口 G3：落地文档 M3 五项 Gate（正文显示/目录跳转/反复打开 10 次内存平稳/加密文件明确报错/容器高度正常）。
- 阻塞处理：iframe 空白查容器显式高度；目录为空降级隐藏侧边栏。

**P4 收尾与打包**
- 目标：错误与边界全覆盖；产出可在净机运行的 x64 可执行文件。
- 任务：T701–T703、T801–T803。
- 入口：G3 通过。
- 出口：G4（错误矩阵行 A07–A14 + 边界 A10/A11 全过）+ G5（净机最小集 A16 + 进程退出 A15）。
- 阻塞处理：净机失败先按 R5 处理（WebView2）；worker 打包态失败按 R1 处理。

**P5 验收与发布**
- 目标：按原文档第 10 章全量验收，文档与产物归档。
- 任务：T901–T903。
- 入口：G5 通过。
- 出口：验收矩阵 18 行全过（失败项修复后全量回归）；偏差回写完成；tag 与归档清单产出。

## 6. 工程规范（执行期约定）

### 6.1 开发循环

- 全程 `wails dev` 开发；每次修改 Go 结构体或方法后，先确认 `frontend/wailsjs/` 已重新生成，再写/改前端调用代码。
- wailsjs 为生成物，禁止手改。
- 阶段内小步提交，不积压跨任务的大提交。

### 6.2 Git 与提交约定

| 项 | 约定 |
